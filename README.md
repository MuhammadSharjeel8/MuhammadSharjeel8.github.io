## Featured Projects

### Real-Time Vehicle Dashboard IoT System

An ESP32-based CAN bus telemetry system that streams vehicle data over Wi-Fi to a real-time C++ desktop dashboard.

### Vision-Based Hazard Navigation System

A real-time RGB-D hazard detection and navigation assistance system designed to identify nearby obstacles and household risks.

### Air Quality Monitoring System

An embedded air quality monitoring system that measures CO₂, temperature, and humidity using an environmental sensor and LCD display.
