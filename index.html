Technical Description

Vision-Based Hazard Navigation System

Real-time RGB-D hazard detection and navigation assistance system designed to identify nearby obstacles and household risks for visually impaired users.

Python OpenCV Intel RealSense D435i Depth Sensing RGB-D Processing Object Detection ESP32 FLIR Lepton I2C VoSPI Wi-Fi/TCP

Developed a vision-based hazard navigation system that uses RGB-D sensing to detect nearby obstacles, motion, doors, people, and household hazards in real time.

  • Integrated the Intel RealSense D435i to process synchronized RGB and depth data.
  • Used depth thresholding and motion analysis to identify nearby obstacles and environmental changes.
  • Supported real-time visualization for debugging hazard detection outputs.
  • Evaluated performance tradeoffs between detection accuracy, frame rate, and system complexity.
  • Built an ESP32-based thermal visualization module to verify FLIR Lepton sensor data.
Technical Description

Developed a vision-based hazard navigation system focused on improving indoor safety for visually impaired users. The main system used an Intel RealSense D435i camera to collect RGB and depth data, allowing the software pipeline to identify nearby obstacles, people, doors, motion, and potential household hazards.

The primary detection pipeline was built in Python using OpenCV and RealSense depth data. Depth-based thresholding was used to detect near-field obstacles, while additional computer vision modules supported object and hazard detection. The project focused on real-time sensing, practical navigation assistance, and balancing detection accuracy with frame-rate constraints.

As a supporting embedded systems component, I developed a thermal sensor visualization module using a FLIR Lepton radiometric thermal camera connected to an ESP32. The purpose of this module was to verify that thermal frame data could be captured, transmitted, reconstructed, and visualized before deeper integration into the navigation system.

The ESP32 controlled the thermal camera over I2C, acquired frame data over VoSPI, and streamed thermal output to a Python application over serial or Wi-Fi/TCP for visualization. This supporting module helped demonstrate how embedded thermal sensing could extend the system’s ability to detect heat-related hazards, while keeping the main project focused on RGB-D navigation and hazard detection.
